# YumGo — Business Glossary

| Thuật ngữ | Ý nghĩa |
|---|---|
| Guest | Người chưa đăng nhập |
| Customer | Người đặt món |
| Restaurant | Thương hiệu/đơn vị kinh doanh |
| Branch | Chi nhánh cụ thể nhận đơn |
| Menu | Danh sách món của branch |
| Menu Item | Một món có thể đặt |
| Cart | Giỏ hàng tạm |
| Checkout | Bước kiểm tra/tính tiền trước khi tạo order |
| Order | Đơn hàng chính thức |
| Order Item | Một dòng món trong order |
| Payment | Trạng thái/đối tượng thanh toán |
| Delivery | Phần giao hàng của order |
| Driver | Tài xế |
| Promotion | Chương trình khuyến mãi |
| Review | Đánh giá sau khi hoàn tất |
| Operations | Nhân sự vận hành nền tảng |
| Admin | Quản trị cấp nền tảng |
| Idempotency | Gửi lại cùng thao tác nhưng không tạo side effect trùng |
| Snapshot | Lưu lại giá trị tại thời điểm nghiệp vụ xảy ra |
| Source of Truth | Nơi được coi là nguồn dữ liệu chính xác nhất |
| Reconciliation | Đối soát trạng thái nội bộ với bên ngoài |
